# BeforeShare Support Website

Static support website for the BeforeShare iOS app.

## Structure

```text
.
├── index.html
├── privacy.html
├── support.html
├── terms.html
├── assets/
│   ├── style.css
│   └── icon.png
└── README.md
```

## Pages

- `index.html` - product landing page for BeforeShare.
- `privacy.html` - privacy policy for App Store review and users.
- `support.html` - support contact, FAQ, troubleshooting, and refund guidance.
- `terms.html` - subscription and lifetime purchase terms.

## Local Preview

Open `index.html` directly in a browser, or serve this directory with any static file server.
